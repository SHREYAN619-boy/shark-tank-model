# Contributor Code of Conduct

## Shark Tank – Startup Investment&#x20;

## Our Pledge

The Shark Tank – Startup Investment Simulator aims to create an open, respectful, and collaborative environment for developers, students, entrepreneurs, and finance enthusiasts.

We are committed to ensuring that everyone can participate without harassment or discrimination, regardless of age, gender, nationality, ethnicity, religion, disability, educational background, or technical experience.

Our goal is to encourage collaboration, responsible software development, and practical learning in entrepreneurship and financial decision-making.

## Our Standards

All contributors are expected to maintain a positive and professional environment.

**Acceptable behavior includes:**

- Using respectful and inclusive language.
- Respecting different opinions, experiences, and technical approaches.
- Providing constructive feedback on code, financial calculations, and documentation.
- Helping beginners understand programming and entrepreneurial concepts.
- Acknowledging others' contributions and ideas.
- Protecting confidential business information and user privacy.
- Collaborating to improve the project's reliability, functionality, and accessibility.

**Unacceptable behavior includes:**

- Harassment, bullying, discrimination, or personal attacks.
- Offensive or disrespectful communication.
- Sharing private information without permission.
- Introducing malicious code or deliberately misleading financial calculations.
- Presenting fictional investment offers as genuine commitments.
- Misrepresenting the project as officially affiliated with the *Shark Tank* television program.

## Our Responsibilities

Project maintainers are responsible for maintaining a respectful and productive environment.

Maintainers are expected to review contributions fairly, provide constructive feedback, address inappropriate behavior, and ensure that project documentation accurately represents the application's capabilities.

They should also encourage responsible financial simulations, protect sensitive information, and promote appropriate testing of new features.

Maintainers reserve the right to edit, reject, or remove contributions that violate these guidelines.

## Responsible Financial Simulation

Because this project involves startup investments and financial decision-making, contributors must follow responsible development practices.

Contributors should:

- Clearly identify investor interactions and investment offers as fictional.
- Avoid unsupported claims about profitability or investment returns.
- Ensure financial calculations and valuation formulas are accurate.
- Protect user-submitted business information and API credentials.
- Avoid presenting simulated evaluations as professional financial advice.
- Test features before submitting changes.

**This project is intended strictly for educational purposes and must not be represented as an official investment platform or a source of verified financial advice.**

## Scope

This Code of Conduct applies to all project-related activities, including GitHub issues, pull requests, code reviews, documentation, discussions, and public interactions representing the project.

All contributors are expected to follow these standards.

## Enforcement

Project maintainers are responsible for addressing violations of this Code of Conduct fairly and consistently.

Depending on the severity of a violation, actions may include:

- Issuing warnings and requesting corrective action.
- Removing inappropriate comments or contributions.
- Rejecting pull requests that violate project guidelines.
- Temporarily or permanently restricting participation.

Reports will be handled respectfully and confidentially where possible.

## Educational Purpose

The Shark Tank – Startup Investment Simulator demonstrates the application of Python programming, financial analysis, business strategy, and interactive software development.

Contributions should support these educational objectives and encourage responsible experimentation.

The application does not provide genuine investment opportunities, guarantee business success, or replace professional financial consultation.
